# 酷睿创显 · 户外照明报价工作台 V5

> 面向 LED 户外照明行业的一站式报价管理系统：客户管理、产品库、智能报价、Excel 导入/导出、邮件收发、客户画像分析、WhatsApp 聊天分析、外贸单证生成，全流程数字化。

## 功能概览

| 模块 | 核心能力 |
|------|---------|
| **📊 仪表盘** | 8 个 KPI 指标卡片（客户/报价/项目/产品总数 + 本月报价/项目 + 待审核），最近报价/项目列表，一键跳转 |
| **🧾 快速报价** | 选客户→选产品→输入数量→自动算价→一键导出 Excel，支持内部参考价对比 |
| **📋 报价管理** | 版本链（草稿/审核/正式）、版本对比、审核锁定、Excel 导出 |
| **👥 客户管理** | 客户档案、联系人、地址、币种、关联报价 |
| **📦 产品库** | 100+ LED 灯具产品，27+ 结构化字段（电气/光学/控制/结构/防护/认证/商业），支持 ext1/ext2/ext3 扩展字段 |
| **📁 项目跟踪** | 按项目分组报价，批量状态流转 |
| **🕘 报价历史** | 全字段筛选（客户/编号/来源/日期），导入溯源 |
| **📥 数据库导入** | 扫描文件夹（xlsx/xls/pdf），自动识别报价单/PI 发票，提取产品+客户+联系人+商品图片，写入报价历史 |
| **✉️ 邮件收发** | IMAP 收件 + SMTP 发件，支持文件导入收件人、正则提取邮箱地址 |
| **🎯 客户画像** | 报价决策辅助：自动同步客户档案和报价统计，手填沟通习惯/风险备忘/报价摘要，一键复制 AI 提示词，导出 MD/JSON |
| **💬 WhatsApp 分析** | 本地浏览器分析导出的聊天记录（.txt），支持多聊天切换、搜索、日历跳转、统计词云，数据不上传服务器 |
| **📄 单证生成** | 集成 TradeKit 外贸单证工具箱，支持 7 种单证（商业发票/形式发票/装箱单/外贸合同/报价单/成本估算/原产地证明），报价数据自动带入，一键导出 A4 横版 PDF |

## 技术栈

- **后端**：Python 3.10+，标准库 `http.server` + `sqlite3`（零框架依赖）
- **前端**：原生 HTML/CSS/JavaScript（单页应用，无构建工具）
- **Excel 解析**：openpyxl + xlrd
- **PDF 解析**：pypdf
- **PDF 导出**：html2pdf.js（TradeKit 单证）
- **邮件协议**：IMAP（收件）+ SMTP SSL（发件）

## 核心特性

### 智能 Excel/PDF 导入

1. **扫描文件夹**：递归扫描 xlsx/xls/pdf 文件
2. **自动分类**：识别报价单、PI 发票、合同
3. **提取数据**：客户名、联系人、电话、地址、产品明细、**商品图片**
4. **图片保存**：提取的图片自动保存到 `data/product_images/`，数据库仅存相对路径
5. **去重机制**：文件 SHA256 哈希 + 商品名称+描述组合去重
6. **写入历史**：记录导入来源、文件位置、导入类型
7. **自动建品**：未匹配的产品自动创建，标记 `Imported` 系列

### 产品描述解析（31 条规则）

产品描述自动解析为结构化字段：

```
输入: "RD-FP-50A,DC24V,3W,6pcs RGBW 5050 SMD,DMX512,IP66,Cree chip,IK10"
输出: model=RD-FP-50A, voltage=DC24V, power=3W, led_count=6pcs,
      cct_color=RGBW, led=5050 SMD, control=DMX512, ip_rating=IP66,
      chip=Cree, ik_rating=IK10, ext1=(未匹配文本)
```

未匹配的文本存入 `ext1` 字段，`ext2`/`ext3` 留给用户手动填写额外描述。
优化：支持 `1m for 23psc` 等含关键词的连续属性值不被错误拆分。

### 报价版本管理

- 状态流转：报价草稿 → 正式版本
- 版本链：同一报价单支持多版本对比，记录每次变更字段（旧值→新值）
- 审核机制：审核为正式版本后锁定，再次编辑自动退回草稿

### 客户画像

- **基础档案**：自动从客户表同步（公司/国家/类型/联系方式）
- **报价统计**：自动从报价历史统计（单数/折扣区间/修改次数/样品单/大小单）
- **沟通习惯**：手填（最佳联系时间/沟通风格/急单型）
- **定制物流**：手填（货代/定制等级/认证/贸易术语）
- **风险备忘**：高亮显示（坑点/丢单记录/价格敏感点）
- **报价摘要**：手填一句话报价策略
- **AI 提示词**：一键复制，喂给 AI 生成报价策略建议
- **导出**：支持 MD / JSON 格式导出

### WhatsApp 聊天分析

- **本地处理**：拖拽上传 `.txt` 聊天文件，数据不上传服务器
- **多聊天切换**：侧栏聊天列表，点击切换
- **消息搜索**：关键词搜索历史消息
- **日历跳转**：选择日期快速定位
- **统计弹窗**：查看消息数量、活跃时段、发送频率等统计
- **词云**：高频词可视化
- **身份标记**：选择"你是谁"对齐消息气泡

### TradeKit 单证生成（集成）

- **7 种单证**：商业发票、形式发票、商业报价单、装箱单、外贸合同、成本估算单、原产地证明
- **数据自动带入**：报价表单的客户/产品/金额自动映射到单证字段
- **补充缺失字段**：在单证中补充 HS 编码、唛头、重量等
- **一键导出 PDF**：A4 横版，专业排版
- **中英双语**：英文为主，中文辅助
- **数据本地**：浏览器存储，不上传服务器

### 邮件集成

- **IMAP 收件**：定时拉取未读邮件，智能识别手机号关联客户
- **SMTP 发件**：SSL 加密，支持多收件人
- **文件导入收件人**：上传 txt/csv/xlsx，正则提取邮箱地址
- **配置管理**：页面内配置 SMTP/IMAP 服务器、账号、授权码

## 部署

### 生产环境建议

1. 使用 Gunicorn / Waitress 等 WSGI 容器（需微调入口）
2. 配置 Nginx 反向代理
3. 定期备份数据库（系统内置每日 03:00 自动备份）
4. 配置邮件 IMAP 定时拉取

### 数据备份

- 自动备份：每日 03:00 执行，保留最近 7 份
- 手动备份：管理页面 → 备份 → 立即备份
- 恢复：上传 .db 备份文件即可恢复
